## 9  Decisions made while building, and their outcome (2 of 2)

Engineering choices of the build phase (2026-11-01 to 11-08). Status as of 2026-11-08.

| Decision | Why | Outcome (what we know) | Verdict |
|---|---|---|---|
| Verify on a real ReGa (restored copy) before the CCU3 | mocks hide how ReGa behaves | Six traps that mocks missed: && does not short-circuit, '!' binds loosely, an undefined variable silently kills a script, numbers assigned to strings, '!= null' is unreliable, a deleted time condition empties its timer. The editors ran on the restored copy only; none has run on the CCU3 yet. | Held |
| Fixed server scripts, values bound as variables | no ReGa code built from user input | Every route runs fixed text and the tests assert it. Price: each feature needs its own Tcl route and tests, and the scripts cannot be shared with other tools. | Held |
| Structure changes on a working copy, put back in one step | the classic editor's own pattern; a failure must not damage a program | Used for actions, conditions and the else part. Every refusal and failure test left the program unchanged, with no stray copy. An active program is re-activated and can run at once: the editor warns first. | Held |
| Program editor in stages: manage, read, actions, conditions, else | the classic editor is about 2,500 lines over raw integer codes | All five stages built in about a week. Reading 54 real programs showed 74 of 79 actions are scripts, so scripts became a first-class action. Time controls can be kept or removed, not created; else-if and weekly programs are open. | Held; three parts open |
| Deploy by installer with backups, not as an add-on | files live in /www (needs a remount); per-file rules for patched files | 17 backups on the CCU3; restore works. One regression: methods.conf shipped as a whole file left 4 methods 'not found' on the CCU3 until the upstream merge. Add-on packaging exists (3 betas) but is not what runs. | Revisit: entry-level patch |
| Tests pin behaviour; two pins for 'ours' | make regressions visible, measure the delta against upstream | 1,390 Tcl tests, 19 browser suites and 219 unit tests made the upstream changes visible at the merge. Price: about 30 follow-up edits and a pin to advance on every merge (slide 7). | Held; derive counts from the registry |
